# 🛡️ Web Attack Detection Tool

A robust cybersecurity tool developed to detect web application vulnerabilities and malicious activity in real-time. This tool analyzes requests and payloads to identify common web attacks using Google Gemini AI.

## 🚀 Features
- **SQL Injection (SQLi) Detection:** Scans input payloads for malicious database injection attempts.
- **Cross-Site Scripting (XSS) Detection:** Identifies script injection and malicious tags.
- **AI-Powered Analysis:** Leverages Gemini to classify web threats accurately.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **AI Model:** Google GenAI (Gemini)
